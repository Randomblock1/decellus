# decellus
Skip Acellus video lessons with a Chrome Extension (click logo for demo)

![icon](icon.png)

![video](yeet.gif)

## How to Install

First, download [the ZIP file](https://github.com/Randomblock1/decellus/releases/download/v1.0.0/decellus.zip).

Then, go to [chrome://extensions/](chrome://extensions/) and enable Developer Mode in the top right corner.

Now, drag-drop the zip file into the Extensions page.

Reload Acellus. Now, you're done!

Share this URL with your friends. Nice and fancy short URL, eh? https://git.io/decellus

## Usage

Click the Decellus icon in your Extensions menu. Optionally, pin it to your top bar to save time.
